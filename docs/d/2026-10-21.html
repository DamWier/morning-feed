Zertifizierungsstellen: Das unsichtbare Vertrauensnetz des Internets

Jedes Mal, wenn der Browser ein kleines Schloss-Symbol zeigt, verlässt er sich auf eine Zertifizierungsstelle (Certificate Authority, CA). Das ist eine Organisation, die digitale Zertifikate ausstellt und damit bestätigt, dass ein Server wirklich zu der Domain gehört, die er vorgibt zu sein. Browser und Betriebssysteme vertrauen nur einer begrenzten Liste solcher Stellen, jede von ihnen kann aber technisch für jede beliebige Domain ein gültiges Zertifikat ausstellen. Genau das macht eine kompromittierte CA so gefährlich: Fallen die privaten Schlüssel in falsche Hände, lassen sich damit täuschend echte Zertifikate für Banken, Shops oder Mailserver fälschen, unsichtbar für die meisten Nutzer. Erst kürzlich wurde bekannt, dass acht private Schlüssel der indischen Zertifizierungsstelle eMudhra gestohlen wurden, deren Zertifikate von Mozilla, Microsoft, Apple und Chrome als vertrauenswürdig eingestuft sind. Browser-Hersteller müssen nun jedes betroffene Zertifikat einzeln zurückziehen, ein Vorgang, der Tage dauern kann.
